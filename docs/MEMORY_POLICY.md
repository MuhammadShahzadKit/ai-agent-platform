# MEMORY POLICY

Version: 1.0

---

# Rules

Every mission creates memory.

Every workflow updates memory.

Every completed task stores memory.

Every important decision stores memory.

Every failure stores memory.

Every approval stores memory.

No memory is permanently deleted.

Archive instead.

---

# Privacy

Mission memory belongs to its owner.

Shared memory requires permission.

Sensitive memory must be encrypted.

---

# Retention

Working Memory

24 hours

Mission Memory

Permanent

Knowledge Memory

Permanent

Experience Memory

Permanent
